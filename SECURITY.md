# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue:

- through GitHub's [Report a vulnerability](https://github.com/Brok3nnn/ingovo-search/security/advisories/new) form (Security tab, Advisories), or
- by email to vitanbalint@gmail.com.

Include what you found, how to reproduce it and the impact you expect. You can expect an acknowledgement within a few days. Please give a reasonable time to fix the issue before disclosing it.

## Scope

This is a showcase repository and is not operated as a hosted service. Reports about the code in this repository are welcome, for example SQL built from user input, prompt injection that escapes the ranking guardrails, session-cookie handling or leaked secrets.

## Supported versions

Only the latest commit on `main` is supported.
